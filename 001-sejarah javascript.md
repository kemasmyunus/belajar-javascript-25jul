**JavaScript**, atau sering disingkat **JS**, pertama kali dibuat pada tahun **1995**. Seorang programmer di Netscape bernama **Brendan Eich** mengembangkan bahasa pemrograman scripting ini untuk dijalankan di **browser Netscape Navigator**.

> **Netscape Communications Corporation**, yang awalnya bernama **Mosaic Communications Corporation**, adalah perusahaan layanan komputer independen asal **Amerika Serikat**. Perusahaan ini awalnya berbasis di **Mountain View, California**, kemudian pindah ke **Dulles, Virginia**.

> **Netscape Web Browser** adalah salah satu browser yang pernah mendominasi pasar. Namun, browser ini kalah bersaing dengan **Internet Explorer** dan kompetitor lainnya dalam "perang browser". Akibatnya, Netscape kehilangan lebih dari **90% pangsa pasarnya** pada pertengahan tahun 1990-an, dan pada tahun **2006** pangsanya tinggal **kurang dari satu persen**.awalnya namanya adalah Mocha, lalu berubah menjadi LiveScript, dan akhirnya menjadi JavaScript.

JavaScript dibuat agar halaman website yang sudah kita buat menggunakan HTML dan CSS bisa lebih interaktif. 
JavaScript sekarang sudah mengalahkan Java Applet dan Flash sebagai bahasa pemrograman untuk membuat halaman web menjadi lebih interaktif, hal ini dikarenakan kemudahan bahasa nya dan juga secara default sekarang semua browser sudah bisa menjalankan JavaScript tanpa harus menginstall aplikasi tambahan seperti JavaApplet dan Adobe Flash Player.
